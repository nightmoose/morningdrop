MorningDrop

Your data drops get checked overnight. You get two lines in the morning.

View the code on GitHub

What it is

MorningDrop is a small local agent for anyone who wakes up to a folder of nightly exports. While you sleep it:

  1. finds the files that are new since last night,
  2. checks every row against a DataContractGate contract, offline,
  3. asks a local Gemma model (via Ollama) for a two-line summary and suggested fixes,
  4. checks Gemma's answer with AISchemaGate, plus grounding checks (right status, real files, no made-up numbers), and
  5. writes a Markdown report and a two-line latest.txt.

No rows leave your machine. No API keys. If the model gets it wrong or isn't running, a plain template writes a correct report from the same facts. On a quiet night, the model isn't called at all.

Try it

git clone https://github.com/nightmoose/morningdrop && cd morningdrop
python -m venv .venv && . .venv/bin/activate && pip install -e .
ollama pull gemma3:4b
morningdrop run && cat reports/latest.txt
